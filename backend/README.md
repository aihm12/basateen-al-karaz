# Basateen Al Karaz Backend

Laravel 13 REST API for بساتين الكرز, using MySQL 8.4 and Laravel Sanctum.

See [the project guide](../README.md) for local startup, environment details, implemented features and remaining integrations. See [API documentation](docs/API.md) for request examples, validation, pricing and authentication rules.

Use the bundled PHP in ../runtime/php/php.exe. Run tests with ../Test-Local.ps1; they target a dedicated MySQL test database. Never commit .env, .env.testing, database files or runtime credentials.
