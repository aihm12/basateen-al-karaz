## موقع المشروع وتشغيله

المجلد الرئيسي: `C:\Users\M\Documents\Codex\Basateen-Al-Karaz`

كود Laravel في مجلد `backend`، والأدوات وقاعدة البيانات المحلية في `runtime`. يوجد رابط للمجلد داخل مخرجات مهمة Codex للوصول إليه بسهولة.

1. انقر مرتين على `Start-Local.cmd` لتشغيل قاعدة البيانات والخادم.
2. افتح [الخادم](http://127.0.0.1:8000) أو [الأقسام](http://127.0.0.1:8000/api/categories) أو [المنتجات](http://127.0.0.1:8000/api/products).
3. للإيقاف: شغّل `Stop-Local.ps1` من PowerShell.
4. للاختبارات: شغّل `Test-Local.ps1` بعد تشغيل قاعدة البيانات.

الخدمات تستمع إلى الجهاز المحلي فقط. لا يوجد تشغيل تلقائي عند بدء Windows؛ أعد فتح ملف التشغيل بعد إعادة تشغيل الجهاز. هذا خادم تطوير محلي.

## ما تم تنفيذه

- الجداول والنماذج والعلاقات للأقسام المتداخلة، المنتجات، الصور، الأحجام والأوزان، مجموعات الخيارات وقيمها، العملاء والعناوين والمفضلة، السلة وعناصرها وخياراتها، الفروع، الطلبات ونسخ تفاصيل عناصرها وخياراتها، الدفع، التوصيل، المناطق والمواعيد، الكوبونات، البنرات، الإشعارات، رموز الأجهزة وسجلات التكامل.
- جدول توفر المنتجات لكل فرع مع كمية اختيارية. القيمة null تعني أن الكمية غير مُدارة محليًا؛ المنتجات التجريبية تستخدمها حتى يُحسم مصدر المخزون.
- 22 مسار API للأقسام والمنتجات والفروع والمواعيد وOTP والحساب والعناوين والمفضلة والسلة والطلبات.
- دخول بالجوال السعودي بصيغة +9665xxxxxxxx وLaravel Sanctum، ورموز دخول محدودة الصلاحية وقابلة للإلغاء.
- رمز OTP عشوائي يُخزن مشفرًا بالتجزئة، صالح لخمس دقائق ولمرة واحدة، مع حدود إرسال وتحقق ومحاولات.
- إعادة حساب السعر من قاعدة البيانات عند الشراء، والتحقق من صلاحية الخيارات والكميات والفرع والعنوان والكوبون وموعد التوصيل.
- منع تكرار الطلب عند إعادة إرسال نفس `Idempotency-Key`، ومعاملة قاعدة بيانات واحدة تشمل الطلب والدفع وحجز المخزون وسجل التكامل وتفريغ السلة.
- الأسعار التجريبية شاملة الضريبة؛ `tax` جزء من الإجمالي وليس مبلغًا يُضاف إليه. الإجمالي = subtotal − discount + delivery_fee. إعداد الضريبة التجريبي 15% للمنتجات، والتوصيل دون احتساب ضريبة منفصلة في هذا الأساس. يلزم اعتماد إعدادات التسعير والضريبة الفعلية قبل الإطلاق.
- حساب الخصم بالهللات وتوزيعه على العناصر قبل احتساب مكوّن الضريبة؛ حفظ أسماء المنتجات والخيارات والأسعار والعنوان والموعد عند الطلب.
- FoodicsIntegration ينشئ سجلًا مؤجلًا داخل المعاملة؛ لا يجري اتصالًا خارجيًا ولا يعتبر الطلب مُزامنًا. تفعيل المتغير وحده لا يضيف موصل Foodics.

## البيانات التجريبية

الأقسام الستة: الفواكه، الخضروات، العصائر، تقاطيع الفواكه، العسل، المكسرات. أُضيف منتج لكل قسم، و7 أحجام إجمالًا، وخيارات النضج والسكر والإضافات، وفرع واحد ومنطقة باسم «منطقة تجريبية» تشمل «حي تجريبي» و21 فترة أسبوعية.

الكوبون `WELCOME20`: خصم 20% بحد أقصى 30 ريالًا للطلب الأول. جميع الأسعار ومواعيد العمل والمناطق تجريبية. لا توجد صور منتجات فعلية بعد.

يوجد طلب واحد موضح بأنه اختبار محلي ناتج عن فحص HTTP، بحالة دفع pending. لم تُحصّل أي أموال أو تُرسل رسائل أو طلبات خارجية.

## المطلوب لاحقًا للإطلاق

بيانات الفرع الحقيقية والمنتجات والأسعار والصور والمخزون ومناطق التوصيل، وقرار مزود OTP وبوابة الدفع وحساب Foodics الخاص ببساتين الكرز. يلزم تنفيذ موصلات المزودين والتحقق من webhooks وإعادة المحاولة، ولوحة إدارة وصلاحيات الموظفين وتغيير حالات الطلبات وإدارة الاسترداد وإلغاء الحجوزات. جداول البنرات والإشعارات متاحة، أما الإشعارات الخارجية وواجهات إدارة هذه البيانات فليست جزءًا من النسخة الحالية.

قبل النشر نجهز HTTPS والاستضافة والنسخ الاحتياطي والمراقبة وإعدادات الإنتاج واختبارات التزامن تحت الحمل. رمز OTP يظهر في الاستجابة محليًا فقط؛ المزود المحلي يرفض العمل في بيئة production. الدفع المتاح حاليًا هو النقدي pending، دون محاكاة نجاح دفع إلكتروني.
